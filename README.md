## 踩过的坑

- `git commit` 前必须先 `git add`，否则报 `nothing added to commit`
- 命令行（git / curl）不会自动走系统代理，需要单独配置：`git config --global http.proxy http://127.0.0.1:7890`
- GitHub 上"授权成功"不等于推送完成，还要执行 `git push`
